# Solarisfilms.es - QA pre-pubblicazione

Data: 2026-08-05  
Uso: checklist prima di rendere indicizzabile `www.solarisfilms.es`.

## Stato sito

- [ ] Dominio `.es` puntato al server corretto.
- [ ] SSL valido per apex e `www`.
- [ ] Redirect apex -> `www`.
- [ ] WordPress o frontend definitivo scelto.
- [ ] Ambiente non indicizzabile durante lavorazione.
- [ ] Produzione indicizzabile solo al go-live.

## Dati societari

- [ ] Ragione sociale spagnola inserita.
- [ ] CIF/NIF inserito.
- [ ] Indirizzo inserito.
- [ ] Telefono corretto.
- [ ] WhatsApp corretto.
- [ ] Email corretta.
- [ ] Footer aggiornato.
- [ ] Privacy policy `.es`.
- [ ] Cookie policy `.es`.

## Contenuti

- [ ] Nessun placeholder visibile.
- [ ] Nessun contenuto italiano residuo nei testi pubblici.
- [ ] Nessuna pagina LCD/fotocromatica/Tecnosolar reintrodotta.
- [ ] Nessun riferimento legale italiano usato come norma spagnola.
- [ ] Garanzie scritte in modo prudente.
- [ ] SafetyShield scritto come soluzione speciale, non pellicola standard.
- [ ] QR certificato validato per contesto spagnolo.
- [ ] CTA coerenti con contatti `.es`.

## Prodotti

- [ ] Immagini prodotto corrette.
- [ ] Schede tecniche collegate solo quando valide.
- [ ] Dati tecnici verificati.
- [ ] Unita di misura corrette.
- [ ] FAQ prodotto contestuali.
- [ ] Download non rotto.
- [ ] Nessun prodotto senza categoria.

## SEO

- [ ] Canonical self su `.es`.
- [ ] Nessun canonical verso `.it`.
- [ ] Hreflang reciproco solo per pagine equivalenti.
- [ ] Title unici.
- [ ] Meta description uniche.
- [ ] H1 unico per pagina.
- [ ] Sitemap `.es` generata.
- [ ] Robots corretto.
- [ ] Search Console `.es` pronta.
- [ ] Nessuna pagina draft in sitemap.
- [ ] Nessuna pagina con placeholder indicizzata.

## Schema / AEO

- [ ] Organization schema con dati spagnoli.
- [ ] LocalBusiness solo se sede e telefono sono validi.
- [ ] Product schema solo con dati verificati.
- [ ] FAQPage solo con domande reali.
- [ ] Orchestra configurato come progetto `.es` separato.
- [ ] Badge Orchestra gestito da plugin/funzione, non hardcoded nel tema.
- [ ] Manifest `.es` non mescolato al manifest `.it`.

## Link e navigazione

- [ ] Menu desktop.
- [ ] Menu mobile.
- [ ] Footer.
- [ ] CTA home.
- [ ] CTA servizi.
- [ ] CTA prodotti.
- [ ] CTA preventivo.
- [ ] WhatsApp.
- [ ] Telefono.
- [ ] Email.
- [ ] Nessun 404 nei link interni.

## Local pages

- [ ] Aree realmente servite.
- [ ] Priorita Tenerife/Canarie coerente.
- [ ] Nessuna promessa nazionale se non operativa.
- [ ] Contatti locali coerenti.
- [ ] Testi non duplicati in modo massivo.

## Performance

- [ ] Immagini WebP/AVIF dove possibile.
- [ ] Dimensioni immagini corrette.
- [ ] Lazy loading sotto fold.
- [ ] Font coerenti.
- [ ] Mobile leggibile.
- [ ] Nessuna sezione troppo scura consecutiva.
- [ ] Core Web Vitals non critici.

## Go-live

- [ ] Backup completo.
- [ ] Rollback definito.
- [ ] DNS TTL controllato.
- [ ] SSL attivo.
- [ ] Robots aperto solo al momento giusto.
- [ ] Sitemap inviata.
- [ ] Analytics attivo.
- [ ] Search Console verificata.
- [ ] Monitor 404 72h.

## No-go immediato

Bloccare pubblicazione se:

- placeholder visibile;
- dati societari mancanti;
- pagina legale assente;
- canonical errati;
- form non funzionante;
- WhatsApp o telefono non corretti;
- contenuti sicurezza non revisionati;
- sitemap include draft o pagine non revisionate.
