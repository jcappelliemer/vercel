# Solaris Films ES WordPress theme

Tema WordPress preparato per `solarisfilms.es`.

## Stato

Pacchetto installabile, non pubblicato. Serve per verificare il rendering WordPress integrale dei contenuti `.es` importati come bozze.

## Contenuti supportati

- `page`
- `post` usato come `articulo`
- `producto`
- `pagina_info`
- `servicio_local`

Le pagine focus tecniche `.es` sono WordPress Pages top-level, non CPT, per mantenere path semplici come `/peliculas-antisolares/`.

## Contatti

Il tema mostra `info@solarisfilms.es` di default. Telefono, WhatsApp e indirizzo sono nascosti finche non vengono configurati come theme mod:

- `solaris_es_phone`
- `solaris_es_whatsapp`
- `solaris_es_address`
- `solaris_es_email`

Questo evita di pubblicare placeholder.

## Orchestra

Il tema non contiene badge AEO Orchestra hardcoded. Orchestra deve restare una funzione/plugin separata.
