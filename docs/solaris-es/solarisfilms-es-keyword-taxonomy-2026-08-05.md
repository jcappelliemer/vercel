# Solarisfilms.es - Tassonomia keyword e naming

Data: 2026-08-05  
Uso: base SEO/AEO per contenuti `.es`, da validare con dati Search Console quando il dominio sara attivo.

## Nota di mercato

Nel mercato spagnolo convivono piu termini:

- `láminas solares`;
- `películas para cristales`;
- `películas para ventanas`;
- `láminas para ventanas`;
- `vinilos para cristales`;
- `vinilos para ventanas`;
- `film para cristales`.

Scelta consigliata Solaris:

- usare `películas para cristales` come termine brand/editoriale principale;
- usare `láminas solares` nelle pagine di controllo solare, per intercettare il linguaggio di mercato;
- usare `vinilos para cristales` nelle pagine decorative/privacy, perche e una ricerca comune nel contesto retail/design;
- usare `láminas de seguridad para cristales` per sicurezza;
- usare i codici prodotto MADICO invariati.

## Fonti osservate per terminologia

- 3M España usa `Láminas para ventanas 3M` e collega comfort, ahorro energetico e sicurezza.
- Competitor/fornitori in Spagna e Canarie usano `lámina de protección solar`, `láminas solares`, `películas para ventanas`.
- Retail spagnolo usa molto `vinilos para ventanas` e `vinilos para cristales` per privacy/decorazione.

Queste fonti non definiscono la strategia Solaris, ma confermano che la tassonomia deve includere sia `películas` sia `láminas/vinilos` a seconda del contesto.

## Naming URL

Regole:

- URL in spagnolo naturale;
- mantenere codici prodotto invariati;
- usare `productos`, non `prodotti`;
- usare `servicio-local`, non `servizio-locale`;
- usare `lo-sabias`, non `lo-sapevi-che`;
- evitare accenti negli slug;
- usare `cristales` nelle URL, non `vidrios`, per linguaggio piu commerciale;
- usare `vidrio` nei testi tecnici quando si parla del materiale/norma.

## Rischi da evitare

- Ottimizzare tutto solo per `películas`, ignorando `láminas`.
- Usare solo `vinilos` per prodotti tecnici.
- Scrivere pagine locali identiche cambiando solo città.
- Usare `vidrio` ovunque nei testi commerciali, rendendo il tono troppo tecnico.
- Pubblicare contenuti legali senza revisione Spagna.
